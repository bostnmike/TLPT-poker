# Marchand game stories

Each published artifact has an individually written entry in `data/marchand-stories.json`, keyed by the stable artifact key. This editorial file is independent of spreadsheet imports; refreshing the canonical collection must not overwrite it.

## Adding a puck

1. Match the date, team and opponent to the official NHL game ID.
2. Read the NHL scoring summary and box score. Check Marchand’s goals, assists, shots and game sequence. Use NHL or team reporting to verify milestone and playoff-series claims.
3. Write a short Marchand-focused narrative, led by the strongest supported detail. Avoid repeating a stock opening or adding an unsupported description of how a goal looked.
4. Identify the artifact accurately. A game-used or warm-up puck from a milestone game is not automatically the puck from the milestone goal. An assist puck belongs to the named scorer’s play.
5. Add readable source links and verification endpoints. Save the date, team and inventory ID so data changes cannot silently leave a mismatched narrative.
6. Apply the owner’s No AI Slop draft checklist: concrete lead, plain language, no filler or manufactured drama, no generic closing line. Re-read against the source facts.
7. Run the Marchand story, page and filter tests, then the full quality gates. Check the rendered dialog at desktop and phone widths.

Missing stories show an honest “coming soon” message without preventing the collection from loading. Publication tests require a story for every current artifact. If a date or team is corrected, re-research the corresponding story before publishing.

The September 27, 2026 pass covers 122 artifacts across 100 official games. Statistics came from NHL game summaries and box scores retained in the prior verified fact-audit cache; record claims were cross-checked against NHL/team reports and career game logs. Before publication, all 100 game box scores were fetched again from the live NHL API: dates, teams and Marchand’s goals, assists, points, shots and ice time matched all 122 entries. No canonical puck statistics were changed as part of this layout/editorial update.
