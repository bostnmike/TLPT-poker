TWIN LAKES POKER TOUR

Install the poker-chip icon

A replacement Home Screen entry with the chip built in.

This setup adds one removable Web Clip named TLPT Cashier. It opens cashier.tlpt.org in an app window. It includes no device-management enrollment, certificates, VPN settings, passwords, or payment data.

Download TLPT Cashier setup

On your iPad, using Safari

  1. Tap the download button above, then Allow if Safari asks to download the profile.
  2. Open Settings → Profile Downloaded. If it is not shown, look under General → VPN & Device Management.
  3. Review TLPT Cashier. It should contain only one Web Clip. Tap Install and complete the iPad’s prompts yourself.
  4. Return to the Home Screen and open the new poker-chip icon. Sign in with your existing cashier password if asked.

The file is unsigned, so Settings may show “Not Signed.” It was prepared for TLPT and does not install a signing or trust certificate. Review its one Web Clip before installing.

Install within 8 minutes of downloading, or download it again. Keep the current working Cashier entry until you have checked the new icon and app window.
Remove this setup later

Open Settings → General → VPN & Device Management → TLPT Cashier → Remove Profile. Removing this profile removes its Home Screen entry; the server’s payments remain saved.
