Prefer the quick written version?

First, open TLPT RSVP in your web browser. Add that app to your Home Screen—not this guide.

iPhone / iPad
  1. Tap Share—the square with the upward arrow.
  2. Choose Add to Home Screen. If it’s missing, check Edit Actions.
  3. Keep the name TLPT RSVP. Leave Open as Web App on, if offered, then tap Add.

If your browser doesn’t offer these options, try opening the app link in Safari.

Android
  1. Use the app’s install button if offered. Otherwise, open your browser’s menu.
  2. Choose Add to Home screen or Install app. Some Chrome versions say Install and create shortcut → Install.
  3. Complete the confirmation shown by your phone.

If your browser doesn’t offer installation, try opening the app link in Chrome.

Then open the yellow TLPT chip. Choose your own name and reply In, Maybe, or Out. The app’s Add to Home Screen button offers help or an available install prompt; your phone handles the final confirmation.
